    Perguntas frequentes

    Quais faculdades de Medicina no Paraná têm edital de transferência aberto agora?

    Hoje, 3 faculdades têm inscrições abertas no Paraná: UniCesumar, FPP, Integrado. A lista é recalculada a cada atualização do radar; confirme o prazo no edital oficial.

    Quando os editais de transferência de Medicina costumam abrir no Paraná?

    Pelo histórico dos editais anteriores, os meses mais frequentes de abertura são agosto (2 faculdades), setembro (1 faculdade), outubro (1 faculdade). É uma tendência, não uma promessa: cada faculdade decide a cada semestre.

    Quem estuda Medicina fora do Brasil pode se inscrever?

    Entre os 3 editais abertos no Paraná, 1 diz que aceita aluno de faculdade estrangeira e 2 dizem que não aceitam. Os demais não informam. Veja o que cada edital exige no guia de quem estuda fora.

    Quanto custa a inscrição nos editais abertos no Paraná?

    Nos editais abertos com taxa conferida, a inscrição vai de R$ 150,00 a R$ 390,00. O valor vale para o edital; confirme no documento oficial.
